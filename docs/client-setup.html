Voice Box · Setup

Getting your voice box running

The box takes a customer's order out loud. This guide gets it talking — from an unopened box to a working setup. No prior technical experience assumed.

First: which setup do you need?

The box needs a "brain" — a computer that listens to what the customer said and decides what to say back. The only real question is whose computer runs it. That changes everything else, so pick this first.

Recommended

Someone else runs the brain

You plug in the box and put it on your WiFi. That's the whole job — about five minutes, done from your phone.

Right for almost everyone. Skip to Connecting the box.
Advanced

You run the brain yourself

Everything runs on your own computer, and nothing leaves your premises. Needs software installed and a few typed commands.

Choose this only if you need it. See Running it yourself.
Worth knowing

Both options keep customer audio private — speech is turned into text on a computer you or your provider controls, never sent to an outside company. The difference is only which computer.

Connecting the box to WiFi

Do this whichever option you picked. You'll need the WiFi password and a phone.

01Plug the box in and wait

Use the USB-C cable. Give it about ten seconds. If it already knows your WiFi it will show its own address on screen — a number like 192.168.1.42 — and you're already finished.

If instead it shows a square QR pattern, it's asking to be set up. Continue.

02Scan the code on the screen

Point your phone camera at the QR code on the box. Your phone will offer to join a network named after the box, something like BOX-C3B4. Tap to join.

If the camera doesn't offer it

Open your phone's WiFi settings and join that network by hand. The 8-character password is printed on the box's screen underneath the code.

03Fill in the short form

A setup page opens by itself once you've joined. If it doesn't, open your browser and go to 192.168.4.1.

Three things to fill in:

FieldWhat to put
WiFi networkPick yours from the list. It only shows 2.4GHz networks — see the note below.
WiFi passwordYour normal WiFi password.
Computer addressThe address of the brain. Your provider gives you this, or find it yourself in step 8.

Press save. The box restarts and joins your WiFi.

Common snag — 5GHz WiFi

The box can only use 2.4GHz WiFi. Most home and shop routers broadcast both and it just works. But if your network is missing from the list, that's almost always why — the network is 5GHz-only.

Using an iPhone hotspot? Turn on Maximise Compatibility in the hotspot settings, or the box cannot see it at all.

04Check it worked

Walk up to the box. It should greet you out loud, once. Say something — it should answer.

If it shows NO SERVER, the box is on WiFi but can't find the brain. The address in step 3 is wrong, or the brain isn't running. See When something's wrong.

Running the brain yourself

Only needed if you chose the advanced option. Everything below happens on the computer that will run the brain — not on the box.

Read this before you start

Two of these steps are genuinely difficult — the speech engines in step 7 need software compiled from source and a 465MB download. They are not click-and-install.

The helper scripts also assume a Mac. On Windows they won't run as written. If that's you, ask your provider for a prepared copy rather than working through this list — this is the honest recommendation, not a formality.

Where do I type these commands?

In an app called Terminal. Press ⌘ Space, type "terminal", press Enter. A window with a text prompt opens. Paste a command, press Enter, wait for it to finish before the next one.

In an app called PowerShell. Press the Start button, type "powershell", press Enter. Paste a command, press Enter, wait for it to finish.

Heads up

The start-up scripts in step 9 are written for Mac and will not run here as written. You can install the pieces, but starting them up needs a developer's help.

In your terminal emulator — usually Ctrl+Alt+T. Paste a command, press Enter, wait for it to finish.

05Install Node.js

This is the engine the brain runs on. Download the LTS version from nodejs.org and run the installer, accepting the defaults.

To confirm it worked, run this. It should print a version number:

Check Node.js
node --version
What good looks like

Something like v22.11.0. If you get "command not found", the install didn't finish — close the terminal, open a new one, and check again before reinstalling.

06Get the project files

Your provider sends you these, usually as a download link or a shared folder. Put them in your home folder so the path is ~/esp — the commands below assume that exact location.

Then install the parts it depends on:

Install dependencies
cd ~/esp/mcp-core && npm install
cd ~/esp/voice-mcp-server && npm install && npm run build

Expect a few minutes and a lot of scrolling text. Warnings are normal; errors in red are not.

07Install the speech engines

Two separate pieces: one turns speech into text, the other turns text back into speech. This is the hard step.

  • whisper.cpp — hearing. Must be compiled on your machine, then a language model downloaded (ggml-small.bin, about 465MB).
  • MOSS-TTS-Nano — speaking. Runs in a Python environment of its own.
Be realistic here

Neither ships with the project and neither has a simple installer. If you're not comfortable compiling software, this is the point to ask your provider for a prepared copy with both already in place. That is a normal request, not a failure.

08Set up your settings file

Start from the supplied example:

Create your settings file
cp ~/esp/config.example.json ~/esp/config.json

Next, two passwords. One lets the box and the brain trust each other; the other controls who may send commands. Without the first, anyone on your WiFi could redirect the box's microphone — so this is not optional.

Generate two secrets
printf 'export ESP_FLEET_TOKEN=%s\nexport ESP_MCP_TOKEN=%s\n' \
  "$(openssl rand -hex 24)" "$(openssl rand -hex 24)" > ~/esp/.env
chmod 600 ~/esp/.env

That writes both into a hidden file the brain reads at start-up. You never need to look at them. Don't paste them into email or chat.

Finally, find this computer's address on your network — this is the Computer address the box asked for back in step 3:

Find your address
ipconfig getifaddr en0
Find your address
ipconfig

Look for "IPv4 Address" under your active adapter.

Find your address
hostname -I | awk '{print $1}'
Putting it together

If that prints 192.168.1.50, the Computer address to type into the box is http://192.168.1.50:8000/upload

09Start it up

Start everything
cd ~/esp && ./start_voice_assistant.sh

Then check each piece came up:

Health check
cd ~/esp && ./check_health.sh

You want five green OK lines. Any red DOWN line names the piece that didn't start — that's your starting point, not a mystery.

Not available on Windows

These start-up scripts are Mac-only. Each piece can be started by hand, but that needs a developer. This is the point where a prepared setup saves real time.

Start everything
cd ~/esp && ./start_voice_assistant.sh

The script uses a Mac command to find your network address, so it may need a small edit on Linux. Everything else works the same.

Run this before every service

The health check is the fastest way to know you're ready. Run it before a busy period — it takes two seconds and turns "why isn't it talking" into a specific answer.

Using it away from the shop

Optional. This lets you reach the brain from somewhere else — checking on it from home, for instance.

Install Tailscale on the computer running the brain and sign in with Google or Microsoft. It creates a private link between your own devices. No terminal needed, and no change to your router.

What this does and doesn't do

This lets you reach the brain from elsewhere. It does not let the box work from a different building — the box still needs to be on the same WiFi as the brain.

Running boxes across separate locations is still being built. It partly works but drops audio under real use, so it isn't ready to rely on.

When something's wrong

What you seeWhat it means
Screen says NO SERVER Box is on WiFi but can't reach the brain. Check the brain is running, and that the Computer address matches step 8. The address changes if your router reassigns it.
Your network isn't in the list Almost always a 5GHz-only network. The box needs 2.4GHz.
It answers, but has no idea about your menu The brain is running but your menu service isn't being reached, so it fell back to a generic assistant. Check that piece is started.
Microphone seems dead The button on top is a physical microphone mute — press it again. No software can override it, by design.
Spoken total differs from the screen Report this. Prices must be calculated, never improvised, and a mismatch is a real fault.
First reply after starting up is slow Normal — the speech models load on first use. Do one throwaway interaction before a busy period.

Starting fresh

To move the box to a different WiFi network, or hand it to someone else: hold the small button on the side for five seconds. That erases the stored WiFi details and its saved password, and the box returns to the QR screen from step 2.

The button on top won't do this — that one only mutes the microphone.
